## Project Milestones 

### Milestone 1: Requirement Gathering & System Design
- Analyzing procurement requirements and standard laptop specifications.
- Designing the Service Catalog item, variable sets, and process workflow.

### Milestone 2: Workflow Automation using Flow Designer
- Creating and configuring the automated trigger on Catalog Item submission.
- Setting up the manager approval process and automatic Catalog Task (SCTASK) generation for the Hardware Fulfillment Group.

### Milestone 3: Testing, Verification & Project Documentation
- End-to-end testing of laptop ordering from Service Portal to task completion.
- Final documentation, report generation, and repository updates.
